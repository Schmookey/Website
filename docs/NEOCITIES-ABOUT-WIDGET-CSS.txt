About page widget alignment — Neocities manual installation

The GitHub version of assets/css/style.css includes the fix, but replacing
your entire live stylesheet might overwrite edits made directly on Neocities.

SAFER INSTALLATION
1. Save a local backup of your existing Neocities assets/css/style.css.
2. Open that existing file in an editor.
3. Paste the CSS below at the very END of the stylesheet, and save.
4. Upload the resulting style.css to Neocities in assets/css/.
5. Reload https://schmookey.xyz/about.html with Ctrl+Shift+R to clear cache.

The CSS is scoped to the right sidebar on the About page. It makes the label,
title and small-print sizes consistent; keeps ListenBrainz together on one
line when space allows; aligns Trakt's footer with its text column; and
removes all widget link underlines, even on hover/focus. Keyboard focus
outlines remain visible.
